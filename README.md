# 🦫 Kapas Zoo

Ett zoospel i webbläsaren, gjort för barn. Du driver ett zoo tillsammans med kapybaran **Kapa**.

**▶ Spela:** https://pwenstrom.github.io/kapas-zoo/

## Det här kan man göra
- 🚶 Gå runt i parken och 🍎 mata djuren, 🤚 klappa dem och släpp in gäster genom att öppna grinden.
- 🦫 Kapybaror badar i lera. Klappa dem så blir de glada!
- 🔨 Bygg ut zoot med nya djur och hägn, träd, blommor, fontän, glasskiosk och lekplats.
- 🔄 Vrid hägnen så dörren hamnar där du vill.
- ❗ Hungriga eller ledsna djur kan rymma – fånga dem och ta hem dem igen.
- ⬆️ Förbättra hägn och zoot så blir det fler djur, mer dricks och fler gäster.
- 🎨 Teman: Vanlig, Jul, Halloween, Påsk, Sommarfest och Enhörning.

## Spela på Android
Öppna länken ovan i Chrome. Pilknapparna och knapparna för mata och klappa visas på skärmen. Vid bygge trycker du två gånger på samma ruta för att placera. Via Chrome-menyn (⋮) kan du välja **Lägg till på startskärmen** (eller **Installera app**) så startar spelet som en egen app och fungerar även utan nät.

## Styrning på dator
| Tangent | Gör |
| --- | --- |
| Piltangenter / W A S D | Gå |
| E eller mellanslag | Klappa, fånga, fylla korgen, öppna grinden |
| F | Mata |
| B | Byggläge |
| R | Vrid hägn när du bygger |
| U | Förbättra zoot |
| M | Ljud av/på |

Spelet sparas automatiskt i webbläsaren. Allt är en enda `index.html` utan några beroenden.
